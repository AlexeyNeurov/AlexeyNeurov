- 🧠 **Agentic AI & RAG** — проектирование мульти-агентных систем и RAG-пайплайнов (LangChain, LangGraph, LlamaIndex), гибридный поиск (Dense + BM25), графы состояний агентов (NetworkX)
- 💬 **LLM & NLP** — глубокое понимание трансформеров (GPT, BERT, RuBERT), fine-tuning под домен, prompt engineering, маршрутизация запросов между моделями
- 👁 **Computer Vision** — детекция объектов и позный анализ (YOLO, DeepLabCut) на PyTorch/TensorFlow
- ⚙️ **MLOps & Backend** — Docker/Docker Compose, FastAPI, PostgreSQL, Qdrant, CI/CD, тестирование (Pytest)
- 📊 **Classical ML** — линейные модели, ансамбли (Random Forest, Gradient Boosting), гиперпараметрическая оптимизация (Optuna, GridSearch)
